# Scrum Poker

Реалтайм веб-приложение для покера планирования (Scrum Poker) с настоящим WebSocket-сервером (Node.js + Express + Socket.io).

## Возможности

- Хозяин создаёт комнату и получает ссылку для команды
- Участники входят по ссылке, вводят имя и попадают в комнату
- Голосование: целое число от 1 до 50 или "☕ не могу оценить"
- Хозяин видит, кто уже проголосовал, но не видит сами оценки до раскрытия
- После раскрытия карт все видят все оценки с именами
- Хозяин может очистить голоса и начать новый раунд

## Запуск локально

Требуется установленный [Node.js](https://nodejs.org/) (версия 18+).

```bash
# 1. Установить зависимости
npm install

# 2. Запустить сервер
npm start
```

Приложение будет доступно на **http://localhost:3000**

Откройте эту ссылку в браузере — вы попадёте на страницу создания комнаты. После создания комнаты вы автоматически становитесь хозяином и получаете ссылку вида `http://localhost:3000/room/abc123`, которую можно отправить участникам команды (в рамках одной локальной сети или после деплоя — кому угодно).

## Деплой (чтобы ссылка работала для реальной команды)

Приложению нужен постоянно работающий сервер (не просто статический хостинг), так как используется WebSocket. Подходят:

### Вариант 1: Render.com (бесплатный тариф)
1. Создайте репозиторий на GitHub и загрузите туда этот проект
2. На [render.com](https://render.com) создайте **New Web Service**, подключите репозиторий
3. Build Command: `npm install`
4. Start Command: `npm start`
5. После деплоя вы получите постоянный URL вида `https://ваш-проект.onrender.com`

### Вариант 2: Railway.app
1. Загрузите проект на GitHub
2. В Railway создайте новый проект из репозитория
3. Railway автоматически определит Node.js-проект и запустит `npm start`

### Вариант 3: Свой VPS
1. Скопируйте проект на сервер
2. `npm install --production`
3. Запустите через процесс-менеджер, например `pm2 start server.js`
4. Настройте nginx как reverse proxy (с поддержкой WebSocket upgrade) и HTTPS через Let's Encrypt

## Технические детали

- Состояние комнат хранится в памяти сервера (без базы данных) — при перезапуске сервера все комнаты сбрасываются
- Комната не требует регистрации — только имя участника
- При закрытии вкладки участник автоматически удаляется из списка комнаты
- Хозяин не голосует — он только управляет процессом (создаёт комнату, раскрывает карты, очищает голоса)
